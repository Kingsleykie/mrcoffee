# Mrcoffee

MrCoffee is a modern coffee shop website project that showcases the brand story, vision and mission, core values, and a curated catalog of high-quality coffee products.

---

## 🌟 Key Features

- **About Us Page:** Displays the brand story, Vision & Mission, and Founders' profiles.
- **Product Catalog & Cart:** Add products to the shopping cart with persistent *Local Storage* management.
- **Responsive Design:** Interactive layouts built with CSS Grid and Flexbox for seamless viewing on both Mobile and Desktop devices.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic web markup structure.
- **CSS3:** Modern layout architecture using Grid & Flexbox.
- **JavaScript (ES6):** DOM manipulation, cart event handling, and browser storage management.
